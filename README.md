# BrPrettyXAML

A Visual Studio plugin for running Python scripts directly from the IDE.

Удобное расширение для Visual Studio Code, которое позволяет запускать внешние Python-скрипты прямо из контекстного меню редактора.

Вся основная логика обработки находится внутри Python-скрипта `runner.py`, что позволяет легко кастомизировать без необходимости переписывать TypeScript-код самого плагина.

Шаг 1. Онлайн-компиляция через GitHub Actions

* Скрипт компиляции находится по этому пути: .github/workflows/compile.yml

Шаг 2. Скачивание готового плагина

* Перейдите на вкладку Actions в верхнем меню вашего репозитория на GitHub.

* В списке слева нажмите на Compile and Package VSIX.

* Справа нажмите кнопку Run workflow -> Run workflow (если сборка не началась автоматически после коммита).

* Начнется процесс онлайн-компиляции (кружок будет мигать желтым). Подождите около 1–2 минут, пока он не станет зеленым.

* Кликните по названию завершившейся задачи (например, "Compile and Package VSIX").

* Прокрутите страницу в самый низ до раздела Artifacts. Там вы увидите файл brprettyxaml-extension. Нажмите на него, чтобы скачать на компьютер ZIP-архив.

Шаг 3. Установка в ваш Visual Studio Code

* Распакуйте скачанный ZIP-архив. Внутри него будет находиться готовый файл расширения brprettyxaml-1.0.0.vsix.

* Откройте ваш рабочий Visual Studio Code.

* Перейдите в раздел Расширения (Extensions) на панели слева (или нажмите горячие клавиши Ctrl+Shift+X).

* В самом верху панели расширений найдите значок трех точек (...) и нажмите на него.

* Выберите пункт Install from VSIX... (Установить из VSIX...).

* В открывшемся окне выберите ваш файл brprettyxaml-1.0.0.vsix.

Расширение установлено!
Теперь при нажатии правой кнопкой мыши внутри любого .xaml или .xml файла (или по файлу в дереве проекта) у вас появится пункт BrPrettyXAML, который запустит скрипт runner.py.
